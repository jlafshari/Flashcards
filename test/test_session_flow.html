Study Session Flow Test

Test Instructions

  1. Open index.html in another tab with some flashcards already added
  2. Go to the Study tab
  3. Initial state should show:
    • ✓ Stats (Total Cards, Reviewed Today)
    • ✓ "Start Study Session" button
    • ✗ Study options (hidden)
    • ✗ Flashcard (hidden)
  4. Click "Start Study Session" button
  5. After first click, should show:
    • ✓ Stats
    • ✓ "Start Study Session" button (still visible)
    • ✓ Study options (categories + direction selector)
    • ✗ Flashcard (still hidden)
  6. Configure your options (select categories, choose direction)
  7. Click "Start Study Session" button again
  8. After second click, should show:
    • ✓ Stats
    • ✓ Flashcard with navigation controls
    • ✓ "End Session" button
    • ✗ Study options (hidden)
    • ✗ "Start Study Session" button (hidden)
  9. Study through some cards
  10. Click "End Session" button
  11. Should return to initial state (only "Start Study Session" button visible)

Test with No Cards

  1. If you have no cards, you should see:
    • ✓ Stats (showing 0 cards)
    • ✓ "No flashcards yet!" message
    • ✗ "Start Study Session" button (hidden)
    • ✗ Study options (hidden)
    • ✗ Flashcard (hidden)

Test with Category Filtering

  1. Add cards with different categories
  2. Click "Start Study Session" to show options
  3. Uncheck some categories
  4. Click "Start Study Session" again
  5. Should only see cards from selected categories
  6. If all categories are unchecked, should show alert: "No cards match the selected categories..."

Expected Behavior Summary

Three States:

  1. Initial State: Stats + "Start Study Session" button only
  2. Configuration State: Stats + Study Options + "Start Study Session" button
  3. Session Active State: Stats + Flashcard + Controls + "End Session" button
