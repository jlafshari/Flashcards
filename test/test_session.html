Study Session Feature - Manual Test

Test Instructions:

  1. Initial State Test
    • Open index.html in a browser
    • Go to "Manage Cards" and add at least 3 cards with different categories
    • Go back to "Study" tab
    • Verify: "Start Study Session" button is visible
    • Verify: Study options (category filter and direction selector) are visible
    • Verify: Flashcard and controls are NOT visible
  2. Start Session Test
    • Select specific categories if available
    • Choose a study direction (Bulgarian → English or English → Bulgarian)
    • Click "Start Study Session" button
    • Verify: "Start Study Session" button disappears
    • Verify: Study options disappear
    • Verify: Flashcard appears with first card
    • Verify: Controls (Previous, Flip Card, Next) are visible
    • Verify: "End Session" button appears at the bottom
  3. Session Navigation Test
    • Click "Flip Card" to see the back
    • Verify: "Easy ✓" and "Review Again ↻" buttons appear
    • Click "Easy ✓" to mark card as easy
    • Verify: Moves to next card
    • Flip the card and click "Review Again ↻"
    • Verify: Card moves to end of deck
  4. Keyboard Shortcuts Test
    • Use Arrow Left/Right to navigate
    • Use Space or Enter to flip card
    • When flipped, use "1" for Easy, "2" for Review Again
    • Verify: All keyboard shortcuts work during session
  5. Session Completion Test
    • Mark all cards as "Easy ✓" (or navigate through all)
    • Verify: Alert shows "Session complete! You reviewed X cards."
    • Verify: Returns to pre-session state with options visible
  6. Manual End Session Test
    • Start a new session
    • Review 1-2 cards
    • Click "End Session" button
    • Verify: Returns to pre-session state
    • Verify: Study options are visible again
  7. Tab Switching Test
    • Start a session
    • Switch to "Manage Cards" tab
    • Switch back to "Study" tab
    • Verify: Session ended automatically
    • Verify: Shows pre-session state
  8. Category Filter Test
    • Before starting session, select only one category
    • Start session
    • Verify: Only cards from selected category appear
    • End session
    • Try changing categories
    • Verify: Can change categories when not in session
  9. Direction Lock Test
    • Choose "English → Bulgarian" direction
    • Start session
    • Try clicking the other direction button
    • Verify: Direction does NOT change during session

Expected Behavior Summary:

  • ✅ Pre-session: Show options and start button, hide cards
  • ✅ In session: Show cards and end button, hide options
  • ✅ Session tracks reviewed cards
  • ✅ Session auto-completes when all cards reviewed
  • ✅ Manual end session returns to start state
  • ✅ Tab switching ends session
  • ✅ Direction and categories locked during session
  • ✅ Keyboard shortcuts work during session
