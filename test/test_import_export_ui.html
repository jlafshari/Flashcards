🧪 Import/Export Functionality Test

Test Instructions

  1. Open the main app (index.html) in another tab
  2. Add some test cards in the "Manage Cards" tab
  3. Click "Export Cards" - should download a CSV file
  4. Open the CSV file in a text editor and verify:
    • English text is in column 1
    • Bulgarian text is in column 2
    • Fields with commas/quotes are properly quoted
  5. Click "Import Cards (Merge)" and select the CSV file
  6. Verify existing cards are preserved and new ones added
  7. Try "Import Cards (Replace)" with confirmation dialog
