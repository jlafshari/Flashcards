⌨️ Keyboard Shortcuts Manual Test Guide

Prerequisites: Open index.html in another browser tab and add at least 3 flashcards before running these tests.

🎯 Test Cases

Test 1: Initial State (Card Not Flipped)

  1. Open the app and go to the Study tab
  2. Verify the card is showing its front side (not flipped)
  3. Verify you see the "Next →" button (not Easy/Review buttons)
  4. Press 1 key
  5. ✓ Expected: Nothing happens (card stays on current index)
  6. Press 2 key
  7. ✓ Expected: Nothing happens (shortcuts only work when flipped)

Test 2: Flip Card with Space

  1. Press Space to flip the card
  2. ✓ Expected: Card flips to show back side
  3. ✓ Expected: "Next →" button disappears
  4. ✓ Expected: "Easy ✓" and "Review Again ↻" buttons appear

Test 3: Easy Button Shortcut (Key 1)

  1. With card flipped, note the current "Reviewed Today" count
  2. Press 1 key
  3. ✓ Expected: Card unflips and moves to next card
  4. ✓ Expected: "Reviewed Today" count increases by 1
  5. ✓ Expected: Feedback buttons disappear, "Next →" button reappears

Test 4: Review Again Shortcut (Key 2)

  1. Press Space or Enter to flip the current card
  2. Note the current "Reviewed Today" count
  3. Press 2 key
  4. ✓ Expected: Card unflips and moves to next card
  5. ✓ Expected: "Reviewed Today" count does NOT increase
  6. ✓ Expected: Feedback buttons disappear, "Next →" button reappears

Test 5: Flip with Enter Key

  1. Press Enter to flip the card
  2. ✓ Expected: Card flips and feedback buttons appear
  3. Press 1 to mark as easy
  4. ✓ Expected: Moves to next card with review count incremented

Test 6: Arrow Key Navigation Still Works

  1. Press ← (Left Arrow) to go back
  2. ✓ Expected: Moves to previous card (unflipped)
  3. Press → (Right Arrow) to go forward
  4. ✓ Expected: Moves to next card (unflipped)
  5. Note: Arrow keys work whether card is flipped or not

Test 7: Last Card Behavior

  1. Navigate to the last card in your deck
  2. Press Space to flip it
  3. Verify both Easy and Review buttons are disabled (grayed out)
  4. Press 1 key
  5. ✓ Expected: Nothing happens (can't go past last card)
  6. Press 2 key
  7. ✓ Expected: Nothing happens (can't go past last card)

Test 8: Shortcuts Only Work on Study Tab

  1. Switch to the "Manage Cards" tab
  2. Press 1 or 2 keys
  3. ✓ Expected: Nothing happens (shortcuts only active on Study tab)
  4. Press Space
  5. ✓ Expected: Nothing happens (no card to flip on Manage tab)

📋 Quick Reference

Key Action When Available
Space or Enter Flip card Study tab, anytime
← → Navigate cards Study tab, anytime
1 Mark as Easy ✓ Study tab, after flipping
2 Mark for Review Again ↻ Study tab, after flipping

✅ All tests passed?

If all tests work as expected, the keyboard shortcuts are working correctly!

New shortcuts integrate seamlessly with existing navigation.
